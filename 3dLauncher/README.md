# 3dLauncher — 3D-вид автомобиля

Штатное приложение **`com.zeekr.carlauncher3d`**, версия **3.0.2726+20250521.abd66f2c4**,
`versionCode=302726`, прошивка Zeekr 001 **5.6d**.
Заводской APK: `/system/priv-app/ZeekrCarLauncher3D/ZeekrCarLauncher3D.apk`.
Приложение использует Unity и открывается внутри основного лаунчера `ecarx.launcher3`.

**Подтверждение кемпинга показывает отдельный сервис `com.geely.pma.bs.modes`.**
Его перевод находится в `../ZeekrKindMode/ZeekrKindMode_RU.apk`; для русских карточки,
внутреннего экрана и подтверждения кемпинга установите обе сборки.

## Перевод интерфейса

| Оригинал | Русская подпись |
|---|---|
| 悬架调节 | Подвеска |
| 露营模式 | Кемпинг |
| 休憩模式 | Отдых |
| 洗车模式 | Мойка |
| 数字车衣 | Облик авто |

Переведены также внутренние экраны и диалоги:

- подвеска: «Максимум», «Высоко», «Стандарт», «Низко», «Минимум», «Готово»;
- мойка: состояние дверей, окон, багажников, зарядных портов, зеркал, климата,
  Auto Hold и отключаемых функций; вход, выход и инструкции для нейтрали;
- кемпинг и отдых: управление окнами, светом, экраном, выбор места и предупреждения
  о перемещении сидений;
- облик автомобиля: кузов, диски, решётка, вкладки цвета и сброс;
- зарядка и режим питомца: кнопки, состояния, единицы измерения и предупреждения.

В `LanguageTable` заменены все 136 значений китайской и английской таблиц,
включая названия карточек. Дополнительно переведены 74 исходных поля TextMeshPro/uGUI
в десяти префабах, 67 именованных Android-ресурсов диалогов и четыре подписи в трёх разметках.
Китайская таблица используется при текущей русской системной локали, английская покрывает
английский язык/резервный выбор, а поля префабов — состояние до загрузки локализации.
Имена ключей, числовые ID и порядок записей сохранены. Новая Unity-локаль `ru` не добавляется.
Китайские ключи в общей таблице и коде остаются: они используются для поиска перевода.

Для активного кемпинга отдельно переведены четыре строковые константы IL2CPP:
«Запереть авто», «Отпереть авто», «Проветрить», «Закрыть окна».
Обработчики смены состояния записывают эти строки прямо в TextMeshPro;
у соответствующих объектов штатного префаба нет компонента `LocalizationText`,
поэтому одного перевода таблиц и исходных подписей недостаточно.
`tools/runtime_strings.py` меняет только четыре значения в `global-metadata.dat`;
индексы литералов, остальные метаданные и `libil2cpp.so` сохраняются.
SHA-256 исходных метаданных проверяется: на другой версии нужен ручной перенос.

**Одного обновления APK для этих четырёх подписей недостаточно.** Unity реально загружает
извлечённый файл `/sdcard/Android/data/com.zeekr.carlauncher3d/files/il2cpp/Metadata/global-metadata.dat`
и сохраняет его между обновлениями. `install.sh` после установки вызывает `sync-runtime.sh`:
сохраняет проверенный бэкап этого файла, готовит совместимые метаданные, останавливает
UI-процессы и атомарно заменяет только данный файл. Данные приложения не очищаются.
Сохраняются также две прежние правки «Лагерь» в известной копии метаданных машины.
Неизвестная версия кэша отклоняется до замены файла. Для доступа нужен root в ADB.

В `assets/aa/catalog.json` обновляются CRC распакованного содержимого Unity-бандлов,
размер и хеш для кэша. Все остальные параметры загрузки и зависимости сохраняются.
Код DEX, нативные библиотеки, 3D-модель, материалы, шрифты и обработчики
нажатий сохраняются побайтово. В `resources.arsc` и трёх бинарных XML меняются только строки
в пулах; ID ресурсов, конфигурации, атрибуты и структура разметки сохранены.
В меню подвески ширина пяти полей подписей увеличена со 100 до 160 единиц внутри штатной
панели: «Максимум», «Стандарт» и «Минимум» помещаются без разрыва слов.
Полной пересборки через apktool нет.

Штатные HarmonyOS Sans SC/EU содержат все буквы перевода; их TextMeshPro-ресурсы
используют динамический атлас и ссылаются на включённые в APK исходные шрифты.
Динамический атлас позволяет добавлять символы из исходного шрифта во время работы:
[документация Unity](https://docs.unity.cn/Packages/com.unity.ugui%402.5/manual/TextMeshPro/FontAssetsDynamicFonts.html).
Результаты проверки текущей сборки и экрана — в `diagnostics/verification.md`.

## Сборка

Нужны Python 3.10+, `zipalign`, `apksigner`, platform-ключи из `../platform/`.
Для работы с Unity-ресурсами используется [UnityPy](https://github.com/K0lb3/UnityPy).

```bash
cd 3dLauncher
python3 -m venv build/venv
build/venv/bin/pip install -r requirements.txt
PATH="$PWD/build/venv/bin:$PATH" ./build.sh
# Если зависимости уже установлены в python3:
./build.sh
```

Сборка проверяет исходные строки и структуру таблиц, сохраняет ID и порядок записей,
повторно читает сохранённые бандлы и сравнивает каждый объект и поток ресурсов.
CRC исходных бандлов сверяются с заводским каталогом.
В готовом ZIP разрешены изменения ровно 12 бандлов, каталога, `resources.arsc`, трёх разметок
и четырёх строковых литералов в метаданных IL2CPP;
далее проверяются подпись и выравнивание APK.

## Установка и откат

```bash
./install.sh
```

Скрипт сохраняет установленный APK в игнорируемой папке `backups/`, проверяет SHA-256 бэкапа
и передаёт APK через `adb push` с отображением прогресса, затем выполняет `pm install -r`.
Передача APK размером 153 МБ по проверенному ADB-подключению занимает около 2–3 минут.
Синхронизация метаданных дополнительно скачивает и передаёт файл примерно 11 МБ,
затем перезапускает только основной и 3D-лаунчер.
Если на машине стоит сохранённый оригинал или известная сборка из `backups/`, бэкап создаётся
локальным копированием после сверки с контрольной суммой APK на машине.
Установка выполняется как обновление системного приложения с прежним platform-сертификатом
и `sharedUserId=android.uid.system`; заводской APK и данные приложения сохраняются.

После установки откройте 3D-вид автомобиля из основного лаунчера.
Если вместо него осталось чёрное поле, перезапустите основной лаунчер без очистки данных:

```bash
adb shell am force-stop ecarx.launcher3
adb shell am start -W -n ecarx.launcher3/.Launcher -f 0x10200000
```

Загрузка Unity может занять около минуты. Проверьте кириллицу в нижних карточках
и меню подвески, а также текст подтверждений мойки/отдыха.
Выбор уровня подвески и подтверждение включения режимов меняют состояние автомобиля.

Откат на оригинал или сохранённую копию:

```bash
adb install -r -d 3dLauncher_original.apk
# либо:
adb install -r -d backups/3dLauncher_<дата>.apk
```

Для восстановления прежних динамических подписей восстановите соответствующий бэкап
метаданных (он сохраняется отдельно от APK):

```bash
./sync-runtime.sh --restore backups/runtime_metadata_<дата>_<pid>.dat
```

## Новая прошивка

```bash
./update.sh                         # получить заводской APK с машины
./update.sh /путь/3dLauncher.apk    # использовать готовый оригинал
```

Предыдущий оригинал заменяется только после успешной сборки и сохраняется в `backups/`.
Формат привязан к проверенной версии приложения: при изменении структуры таблиц,
префаба или исходного текста сборка остановится для ручного переноса.
