# platform — общее для сборки

| Файл | Что |
|---|---|
| `framework-res.apk` | `framework-res.apk` машины (прошивка 5.6d, Android 9). Нужен apktool, чтобы корректно разворачивать ссылки `@android:` в системных приложениях (SystemUI) |
| `platform.pk8`, `platform.x509.pem` | platform-ключ прошивки: им подписаны системные приложения и все сборки в этом репозитории. Без него Android не даст заменить системное приложение (`sharedUserId=android.uid.system`) |

> ⚠️ **Репозиторий публичный, ключ лежит в нём открыто.** Любой, кто его скачает, может подписать приложение
> с правами system uid для машины с этой прошивкой. Если это нежелательно — убрать ключи из репозитория
> (и из истории, например `git filter-repo`), а сборку вести с локальной копией ключа.

Ссылки на эти файлы в скриптах — `../platform/...`.
