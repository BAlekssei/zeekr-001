# XCMyCar — «Мой автомобиль»

Штатное приложение `com.ecarx.mycar`, версия **dc1e-20250102**, `versionCode=20250102`,
прошивка машины **5.6d**. Заводской APK: `/system/app/XCMyCar/XCMyCar.apk`.
Иконка с машиной сверху и подписью `我的汽车` относится к этому приложению.
Главный экран: `com.zeekrlife.myCar.view.MainActivity`.

Большая карточка `车况` на главном экране реализована отдельно, внутри `ecarx.launcher3`.
Её перевод включён в `../XCLauncher3/XCLauncher3_ya_widget.apk`, исходник словаря —
`../XCLauncher3/ya_widget/ru/vehicle-card.json`. Для перевода обоих экранов нужны оба APK.

## Что изменено

| Файл | Изменение |
|---|---|
| `ru/strings.xml` | 437 строк: название приложения, поездки, статистика, потоки энергии, зарядка, давление и предупреждения шин, техобслуживание, сведения об авто, нарушения ПДД и общие диалоги |
| `patches/01-locale-number-format.patch` | исправление вылетов из-за десятичной запятой в трёх расчётных участках |
| `smali/.../NumberFormats.smali` | создание `DecimalFormat` с символами `Locale.US`, независимо от языка интерфейса |
| `patches/02-layout-text.patch` | тексты, зашитые в разметку: подпись виджета, загрузка, библиотечные заглушки |
| `patches/03-tire-warning-labels.patch` | русские названия четырёх колёс в сообщениях об утечке воздуха для карточки |

Строки добавляются в `values`, `values-ru` и `values-zh-rCN`: интерфейс остаётся русским,
даже если машина восстановит китайский язык. Идентификаторы ресурсов и подстановки `%s`/`%d`
сохраняются; скрипт останавливается, если имя отсутствует в новой версии или отличаются подстановки.
Логи, аналитика, протокол голосового управления и диагностика Sensors Analytics не переводятся.
Телефоны сервиса, VIN, обозначения модели и численные значения не заменяются.

## Почему приложение падало

В журнале машины сохранены 22 падения XCMyCar за 02–03.11.2026. Последние два:

```text
java.lang.NumberFormatException: For input string: "46,0"
    at java.lang.Float.valueOf(...)
    at com.zeekrlife.myCar.common.TripHelper.h(...)
    at com.zeekrlife.myCar.common.TripHelper.H(...)
    at com.zeekrlife.myCar.common.TripHelper.J(...)
    at com.zeekrlife.myCar.driving.repository.StatisticsItemRepository.d(...)
```

Сток форматирует число через `new DecimalFormat("#.0")` с текущей локалью,
а затем вызывает `Float.valueOf` для полученной строки. При `ru-RU` получается `46,0`,
которое Java не принимает как число с плавающей точкой. Падение происходит при загрузке
статистики поездок; раньше оно также происходило в фоновых задачах RxJava.
Выдержка исходного журнала: `diagnostics/crash-before.log`.

Такая цепочка найдена и исправлена во всех трёх местах приложения:

- `TripHelper.h(Float)` — округление показателей поездки;
- `DistanceUtils.a(float)` — расстояние в километрах;
- `TripRegister` — усреднение и запись истории расхода на 100 км.

Внутренний формат теперь использует `DecimalFormatSymbols.getInstance(Locale.US)`.
Шаблон `#.0`, исходный режим округления HALF_EVEN и отсечение отрицательных значений
в `TripHelper.h` сохранены. Глобальный язык не меняется. `Locale.ROOT` здесь не используется:
на Android машины он при проверке дал десятичную запятую при русской локали.
Форматирование графика, результат которого выводится на экран без обратного разбора, остаётся штатным.

## Структура и сборка

```text
XCMyCar_original.apk   заводской APK, снятый с машины до правок
XCMyCar_RU.apk         русская сборка с исправлением вылетов
ru/                   переводы по именам ресурсов
patches/              точечные изменения кода и разметки
smali/                вспомогательный класс числового формата
tools/translate.py    перенос перевода и проверка подстановок
tests/                проверка реальных классов APK в пяти локалях на Android
diagnostics/          выдержки журналов и результаты проверки
build.sh              распаковка, перевод, патчи, сборка и подпись
install.sh            бэкап текущего APK и установка обновления
update.sh             получение нового заводского APK и пересборка
```

Нужны `apktool` 3.x, `python3`, `patch`, `unzip`, `zipalign`, `apksigner`.
Используется чистый встроенный framework apktool: приложение собрано под API 32,
а системный framework машины относится к API 28. Ключи — `../platform/`.
Пересобираются `classes.dex` и `classes2.dex`; `classes3.dex` сохраняется из стока байт-в-байт.

```bash
./build.sh
```

## Установка и откат

```bash
./install.sh
adb install -r -g ../XCLauncher3/XCLauncher3_ya_widget.apk
```

XCMyCar устанавливается через `adb install -r` как обновление системного приложения
с прежней platform-подписью. Исходный `/system/app/XCMyCar/XCMyCar.apk`, история поездок
и настройки сохраняются, перезагрузка не требуется. Бэкап текущего установленного APK —
в игнорируемой папке `backups/`. Для лаунчера перед установкой можно сохранить APK по пути
из `adb shell pm path ecarx.launcher3`.

Откат XCMyCar на заводской APK или сохранённую сборку:

```bash
adb install -r -d XCMyCar_original.apk
# либо adb install -r -d backups/XCMyCar_<дата>.apk
```

У заводской сборки исходная ошибка десятичной запятой сохранится.
Откат лаунчера — установка его сохранённого APK через `adb install -r -d`.

## Проверка исправления на Android

Нужны JDK 17, Android SDK с build-tools 34 и android-28, подключённая машина.
`JAVA_HOME`, `ANDROID_SDK_ROOT` и `ANDROID_BUILD_TOOLS` можно переопределить.

```bash
JAVA_HOME=/путь/к/jdk ./tests/run-locale-regression.sh
```

Тест запускает реальные `NumberFormats.create`, `DistanceUtils.a` и `TripHelper.h`
из собранного APK отдельным процессом `dalvikvm64`. Проверяет 180 расчётов в локалях
`ru-RU`, `en-US`, `zh-CN`, `de-DE`, `ar-EG`, включая дробные, нулевые и отрицательные значения.
Настройки языка автомобиля и данные приложения тест не изменяет.
Результаты ручной проверки установленных экранов — в `diagnostics/verification.md`.

## Новая прошивка

```bash
./update.sh                    # берёт заводскую копию из /system/app/XCMyCar
./update.sh /путь/XCMyCar.apk   # либо из готового файла
./install.sh
```

Предыдущий оригинал сохраняется в `backups/`. Патчи применяются без fuzz;
при изменении структуры новой версии сборка остановится для проверки и ручного переноса.
