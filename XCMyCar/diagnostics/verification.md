## Проверка причины вылета

В исходном crash-буфере 22 записи `Process: com.ecarx.mycar`.
Последний сбой — **03.11.2026 20:58:00.994**, `NumberFormatException: "46,0"`,
`TripHelper.h → H → J → StatisticsItemRepository.d`.

Тест `tests/LocaleRegression.java` запущен на машине через `dalvikvm64` против реальных
классов собранного APK. **180 проверок прошли** для `ru-RU`, `en-US`, `zh-CN`, `de-DE`, `ar-EG`.
Проверялись `NumberFormats.create`, `DistanceUtils.a`, `TripHelper.h`, исходное округление
и сохранение текущей локали процесса. Результат — `locale-regression.log`.

Выяснено отдельно: `DecimalFormatSymbols.getInstance(Locale.ROOT)` на этой машине
при русской локали дал запятую (ошибка разбора `",0"` в первоначальном тесте).
В итоговой сборке используется явная `Locale.US`; проверка прошла для всех пяти локалей.
