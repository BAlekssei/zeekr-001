## Как устроено

Все приложения — штатные системные APK прошивки 5.6d. Для каждого в папке лежат стоковый `*_original.apk`,
готовая сборка (`*_RU.apk`, `systemui_patched_final.apk`, `XCLauncher3_*.apk`), скрипты `build.sh` / `install.sh`
и свой README с описанием. Сборки подписаны platform-ключом из `platform/`.

- перевод — подмена строк и разметки в ресурсах (SystemUI, настройки, климат, уведомления) и, где текст зашит в код, в smali;
- **Яндекс Музыка**: нота в нижней панели (`SystemUI/`) открывает приложение, карточка медиа на главном экране
  (`XCLauncher3/ya_widget/`) показывает трек, обложку и управляет воспроизведением через `MediaSession`;
- APK хранятся в Git LFS.

> ⚠️ В `platform/` лежит приватный platform-ключ, а репозиторий публичный — см. `platform/README.md`.
