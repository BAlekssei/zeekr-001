# ZeekrKindMode — подтверждение кемпинга и сообщения режимов

Пакет `com.geely.pma.bs.modes`, версия **dc8155-20251124**, `versionCode=20251124`.
Заводской APK: `/vendor/app/ZeekrKindMode/ZeekrKindMode.apk`, прошивка Zeekr 001 5.6d.

Карточка и Unity-экран кемпинга находятся в `../3dLauncher/`, но подтверждение входа/выхода
показывает отдельный сервис режимов. Поэтому для перевода обоих нужны **два APK**.

Переведены 47 именованных ресурсов: заголовок, описание, вход/выход и уведомления кемпинга,
общие кнопки, сообщения об условиях включения/выхода и низком заряде, комфорт на стоянке.
Остальные экраны сервиса этим патчем не переводятся.

В предупреждении кемпинга сохранены все действия оригинала: комфорт на стоянке,
центральный замок, закрытие окон, выключение наружного света, изменение скорости
вентилятора и автоматический выход при заряде ниже 20%.

## Файлы и сборка

```text
ZeekrKindMode_original.apk  оригинал с машины
ZeekrKindMode_RU.apk        готовая сборка с переводом
ru/strings.json            исходные строки, имена ресурсов и русский перевод
tools/translate.py         замена строк и контроль состава APK
tools/android_strings.py   перенос пула строк с сохранением ID ресурсов
build.sh                   сборка и platform-подпись
install.sh                 проверенный бэкап, передача с прогрессом, установка
update.sh                  получение нового оригинала и пересборка
diagnostics/               результаты проверки
```

Нужны `python3`, `zipalign`, `apksigner`, для установки — `adb`.
Ключи — из `../platform/`.

```bash
./build.sh
./install.sh
```

Меняется только глобальный пул строк `resources.arsc`: ID, пакеты и конфигурации ресурсов
сохраняются. Исходные значения и подстановки проверяются. DEX, нативные библиотеки,
манифест, разметки и остальные ZIP-файлы сохраняются побайтово.
Установка — обновление штатного пакета с прежним platform-сертификатом без очистки данных.

Для проверки откройте «Кемпинг» в 3D-лаунчере и проверьте подтверждение.
Нажмите «Отмена», если не хотите включать режим. Если подключение сервиса не восстановилось,
перезапустите основной лаунчер:

```bash
adb shell am force-stop ecarx.launcher3
adb shell am start -W -n ecarx.launcher3/.Launcher -f 0x10200000
```

Откат:

```bash
adb install -r -d ZeekrKindMode_original.apk
# либо APK из backups/
```

Перенос на новую прошивку:

```bash
./update.sh
./update.sh /путь/ZeekrKindMode.apk
```

Предыдущий оригинал сохраняется в `backups/` и заменяется только после успешной сборки.
